일반

Refit은 AI 기반의 고객 지원 솔루션입니다. 웹사이트에 간편하게 설치할 수 있는 챗봇을 제공하여 방문자의 질문에 즉시 응답하고, 필요한 경우 실시간 채팅 지원을 연결해 드립니다.

빠른 응답으로 고객 만족도를 높이고 매출 증대에 도움이 됩니다.

Refit 서비스 시작은 매우 간단합니다. 회원가입 후 대시보드에서 API 키를 발급받고, 제공되는 설치 코드를 웹사이트에 삽입하기만 하면 됩니다.

추가적인 개발 지식이나 복잡한 설정이 필요하지 않습니다. 5분 이내에 여러분의 웹사이트에 AI 챗봇을 설치할 수 있습니다.

API 관련

API 키는 대시보드의 'API 관리' 메뉴에서 확인하실 수 있습니다. 처음 서비스를 시작할 때 자동으로 API 키가 발급되며, 필요한 경우 이 페이지에서 키를 재발급하거나 관리할 수 있습니다.

API 호출 한도는 사용 중인 요금제에 따라 다릅니다. 무료 플랜의 경우 월 1,000회 호출로 제한되며, 프로 플랜은 월 10,000회, 비즈니스 플랜은 월 50,000회까지 가능합니다.

필요에 따라 맞춤형 엔터프라이즈 플랜을 통해 더 높은 한도를 설정할 수 있습니다.

채팅 관련

채팅 기록은 기본적으로 90일 동안 보관됩니다. 프로 및 비즈니스 요금제 사용자는 최대 1년까지 채팅 기록을 보관할 수 있으며, 엔터프라이즈 요금제는 보관 기간을 사용자 지정할 수 있습니다.

채팅 기록은 대시보드의 '채팅 관리' 섹션에서 확인하고 관리할 수 있습니다.

네, 채팅 세션은 대시보드의 '채팅 관리' 섹션에서 언제든지 수동으로 삭제할 수 있습니다. 개별 채팅 세션 또는 여러 세션을 한 번에 선택하여 삭제할 수 있습니다.

또한 특정 기간이 지난 채팅 세션을 자동으로 삭제하도록 설정할 수도 있습니다.

네, 채팅 위젯의 디자인은 다양한 방식으로 커스터마이징할 수 있습니다. 색상, 폰트, 아이콘, 메시지 텍스트 등을 변경할 수 있으며, 이러한 설정은 대시보드의 '채팅 관리' > '위젯 설정' 메뉴에서 관리할 수 있습니다.

프로 이상의 요금제에서는 CSS를 통한 고급 커스터마이징도 지원합니다.

결제 관련

네, 언제든지 요금제를 업그레이드하거나 다운그레이드할 수 있습니다. 업그레이드의 경우 즉시 적용되며, 남은 기간에 대한 차액이 일할 계산되어 청구됩니다. 다운그레이드는 현재 결제 주기가 끝난 후 다음 결제 주기부터 적용됩니다.

결제 후 7일 이내에 요청하시면 전액 환불이 가능합니다. 7일 이후에는 미사용 기간에 대해 일할 계산된 금액을 환불해 드립니다. 환불 요청은 대시보드의 '결제 관리' 메뉴 또는 고객 지원 이메일(support@refit.ai)을 통해 접수해 주세요.
