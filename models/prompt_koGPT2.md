# KoGPT2 문서 기반 응답 프롬프트 가이드라인

---

## 1. 목적

이 가이드는 KoGPT2가 **검색된 Top-3 문서**를 기반으로  
질문에 대한 응답을 정확하고 일관되게 생성할 수 있도록 설계되었습니다.  
KoGPT2는 절대로 **문서에 없는 내용을 임의로 생성해서는 안 됩니다.**  
**실제로 기재되어 있는 내용만을 참고하여 답변합니다.**

---

## 2. 프롬프트 구조

```
[문서]
<문서1 내용>

<문서2 내용>

<문서3 내용>

[질문]
<사용자 질문>

[답변]
```

- `[문서]`에는 **FAISS를 통해 검색된 상위 3개 문서의 텍스트**가 포함됩니다.
- 각 문서는 줄바꿈(빈 줄)으로 구분합니다.
- 문서 개수는 3개 이하로 제한됩니다.
- 질문과 문서는 반드시 명확히 구분되어야 하며, `[질문]` 태그 뒤에 질문을 작성합니다.

---

## 3. 생성 규칙 (KoGPT2 응답 시 따라야 할 것)

1. **오직 문서에 포함된 내용만 사용해서 응답합니다.**
2. **새로운 정보를 추측하거나 창작하지 않습니다.**
3. **문서에 없는 정보, 추측 또는 감정 표현을 포함하지 않습니다.**
   - 예시: "~ 추천해요", "~ 좋을 것 같아요", "~ 아마 그럴 수 있어요"
   - 위와 같은 표현이 포함된 응답은 **무조건 배제**합니다.
4. 문서에 관련된 정보가 없을 경우, 다음과 같이 응답합니다:
   ```
   해당 문서에는 질문에 대한 답변이 포함되어 있지 않습니다.
   ```
5. **모든 응답은 1~2개의 간결한 문장으로 작성합니다.**
6. **가능하면 "문서에 따르면", "자료에 따르면" 등의 표현을 사용합니다.**
7. **마침표 등 문장부호를 포함하여 완전한 문장을 작성합니다.**
8. **숫자, 조건, 날짜, 금액 등의 항목은 문서에 있는 그대로 정확하게 복사하거나 재구성합니다.**
9. **요약은 피하고, 문서 문장을 기반으로 응답을 구성합니다.**

---

## 4. 기대 응답 예시

### 입력:
```
[문서]


[질문]
무이자 할부가 몇개월까지 가능한가요?

[답변]
```

### 기대 응답:
```
oo카드는 3개월 무이자 할부를 제공합니다.
```

## 5. 실전 팁

- 최대 3개의 문서를 넘지 말 것 (토큰 수 제한 주의)
- 문장 순서와 문서 순서에 따라 응답 내용이 달라질 수 있음
- 문서에 포함된 숫자, 조건, 날짜, 금액 등을 그대로 반영해야 함
- 요약보다 문서의 표현을 재활용하거나 재구성해 사용할 것

---

## 6. 개별 정보 활용

- 질문이 고객 데이터 기반일 경우, 반드시 **해당 고객 정보 파일**의 내용을 활용하여 답변해야 합니다.
- 고객 정보에는 다음 항목이 포함될 수 있습니다:
  - 최근 구매 내역
  - 배송 현황
  - 제품의 금액 및 결제 정보
- 고객 관련 질문일 경우, 해당 문서가 존재하지 않으면 `"해당 문서에는 질문에 대한 답변이 포함되어 있지 않습니다."`를 반드시 반환합니다.
