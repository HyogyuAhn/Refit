# KoGPT2 문서 기반 응답 프롬프트 가이드라인

---

## 1. 목적

이 가이드는 KoGPT2가 **검색된 Top-3 문서**를 기반으로  
질문에 대한 응답을 정확하고 일관되게 생성할 수 있도록 설계되었습니다.  
KoGPT2는 절대로 **문서에 없는 내용을 임의로 생성해서는 안 됩니다.**
**실제로 기재되어 있는 내용만을 참고하여 답변합니다.**

---

## 2. 프롬프트 구조

```
[문서]
<문서1 내용>

<문서2 내용>

<문서3 내용>

[질문]
<사용자 질문>

[답변]
```

- `[문서]`에는 **FAISS를 통해 검색된 상위 3개 문서의 텍스트**가 포함됩니다.
- 각 문서는 줄바꿈(빈 줄)으로 구분합니다.
- 문서 개수는 3개 이하로 제한됩니다.
- 질문과 문서는 반드시 명확히 구분되어야 하며, `[질문]` 태그 뒤에 질문을 작성합니다.

---

## 3. 생성 규칙 (KoGPT2 응답 시 따라야 할 것)

1. **오직 문서에 포함된 내용만 사용해서 응답합니다.**
2. **새로운 정보를 추측하거나 창작하지 않습니다.**
3. **문서에 없는 정보, 추측 또는 감정 표현을 포함하지 않는다.**
   **예시: ~ 추천해요, ~ 좋을 것 같아요 등의 표현**
   **위의 내용이 들어간 답변은 "무조건" 배제하여 답변을 진행한다.**
4. 문서에 관련된 정보가 없을 경우, 다음과 같이 응답합니다:
```
해당 문서에는 질문에 대한 답변이 포함되어 있지 않습니다.
```

4. **모든 응답은 1~2개의 간결한 문장으로 작성합니다.**
5. **가능하면 "문서에 따르면", "자료에 따르면" 등의 표현을 사용합니다.**
6. **마침표 등 문장부호를 포함하여 완전한 문장을 작성합니다.**

## 4. 기대 응답 예시

### 입력:
```
[문서]


[질문]
무이자 할부가 몇개월까지 가능한가요?

[답변]
```

### 기대 응답:
```
oo카드는 3개월 무이자 할부가 가능합니다.
```

## ✅ 기대 응답 예시 (정상 응답들)
1. 문서에 따르면 삼성카드는 3개월 무이자 할부를 제공합니다.
2. 자료에 따르면 배송은 평균 2일 이내에 완료됩니다.
3. 문서에 따르면 교환은 수령일로부터 7일 이내에 가능합니다.
4. 자료에 따르면 회원 등급은 총 4단계로 구성되어 있습니다.
5. 문서에 따르면 A상품은 재고가 소진되었습니다.
6. 자료에 따르면 취소 수수료는 10%입니다.
7. 문서에 따르면 방문 상담은 사전 예약이 필요합니다.
8. 자료에 따르면 해당 서비스는 서울 지역만 가능합니다.
9. 문서에 따르면 제품 보증 기간은 1년입니다.
10. 자료에 따르면 결제 수단은 카드, 무통장입금, 간편결제가 있습니다.
11. 문서에 따르면 회원 가입 시 3,000포인트가 지급됩니다.
12. 자료에 따르면 환불은 영업일 기준 3일 내 처리됩니다.
13. 문서에 따르면 이 이벤트는 5월 31일까지 진행됩니다.
14. 자료에 따르면 고객센터 운영시간은 평일 오전 9시부터 오후 6시입니다.
15. 문서에 따르면 본 상품은 쿠폰 적용이 불가합니다.
16. 자료에 따르면 정기 배송은 매월 첫째 주에 출고됩니다.
17. 문서에 따르면 사용 후기는 로그인 후 작성 가능합니다.
18. 자료에 따르면 SMS 수신 동의 시 할인 혜택이 제공됩니다.
19. 문서에 따르면 교환 요청 시 왕복 배송비가 발생합니다.
20. 자료에 따르면 해당 강의는 수강 기간 연장이 불가능합니다.
21. 문서에 따르면 이 상품은 해외 배송이 지원되지 않습니다.
22. 자료에 따르면 적립금은 다음 구매 시 사용 가능합니다.
23. 문서에 따르면 본 서비스는 모바일 앱에서만 이용 가능합니다.

## 6. 실전 팁

- 최대 3개의 문서를 넘지 말 것 (토큰 수 제한 주의)
- 문장 순서와 문서 순서에 따라 응답 내용이 달라질 수 있음
- 문서에 포함된 숫자, 조건, 제한 등을 정확하게 추출하여 응답에 반영한다.

---

## 7. 개별 정보
- 고객의 정보가 들어있는 파일을 바탕으로 답변을 진행한다.
- 고객의 정보에 있는 내용에 관련된 답변을 반환해야한다.
- 고객의 정보에는 최근 구매 내역(제품명, 배송현황, 제품의 금액, 결제 정보 등)이 담겨져있다.
